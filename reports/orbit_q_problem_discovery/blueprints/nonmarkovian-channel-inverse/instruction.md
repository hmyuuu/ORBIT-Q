# Causal-break non-Markovian channel identification

Implement `run_solution(config)` in `/root/solution_110.py`.

A system qubit `S` repeatedly collides with a retained memory qubit `M`.  Some
public interventions discard and reprepare `S`, but `M` is never reset within
a probe.  Consequently, the output after a causal break can still depend on
the earlier controls.  Identify the six shared physical parameters

```text
(g, phi, zeta, omega, damping_rate, bath_ground_weight)
```

in exactly that order.

Use the ordered two-qubit basis `|00>, |01>, |10>, |11>`, with `S` first.  A
collision lasting `dt` is generated by

```text
H_col = [[ zeta/2,              0,                    0,       0],
         [      0,        -zeta/2,       g*exp(-i*phi),       0],
         [      0, g*exp(+i*phi),              -zeta/2,       0],
         [      0,              0,                    0,  zeta/2]],

U_col(dt) = exp(-i * dt * H_col).
```

Every probe begins in `|00>`.  Prepare each qubit by applying `Ry(polar)` and
then `Rz(azimuth)`, using `probe["system_prep"]` and
`probe["memory_prep"]`, respectively.  Rotations use
`Ra(theta) = exp(-i*theta*sigma_a/2)`.

For each entry of `probe["steps"]`, in list order:

1. If `reset_system` is true, apply the trace-preserving reset channel
   `{|0><0|, |0><1|}` to `S`, then apply `Ry` and `Rz` with the two angles in
   `reset_prepare`.  If it is false, `reset_prepare` is `null` and nothing is
   done in this substep.  The memory is not reset.
2. Apply `Rx(control[0])`, `Ry(control[1])`, and `Rz(control[2])` to `S`.
3. Apply `U_col(duration)` to `(S,M)`.
4. Apply `Rz(omega * duration)` to `M`.
5. Apply generalized amplitude damping to `M` with

   ```text
   gamma = 1 - exp(-damping_rate * duration),  p = bath_ground_weight,

   K0 = sqrt(p) * diag(1, sqrt(1-gamma)),
   K1 = sqrt(p) * [[0, sqrt(gamma)], [0, 0]],
   K2 = sqrt(1-p) * diag(sqrt(1-gamma), 1),
   K3 = sqrt(1-p) * [[0, 0], [sqrt(gamma), 0]].
   ```

After the one-based step numbers in `config["readout_after"]`, evaluate every
two-qubit Pauli string in `config["observables"]`.  A string such as `"XI"`
means `X` on `S` tensor identity on `M`.  The production instance exposes only
system Pauli readouts; the retained memory is not measured.  Concatenate real
expectations first by readout step and then by observable order.  No
measurement collapse occurs at these readouts.

## Public configuration schema

- `n_qubits` is integer `2`; `system_qubit` is `0`; `memory_qubit` is `1`.
- `parameter_names` is the six-name list shown above.
- `parameter_bounds` has shape `(6,2)` and contains closed `[lower, upper]`
  bounds in `parameter_names` order.
- `readout_after` is a strictly increasing list of one-based step numbers.
- `observables` is a list of length-two strings over `I`, `X`, `Y`, and `Z`.
- `training_probes` and `heldout_probes` are lists of probe dictionaries.
- Each probe has real two-element `system_prep` and `memory_prep` lists and a
  `steps` list.  Every step has positive real `duration`, a three-real
  `control` list, Boolean `reset_system`, and either a two-real
  `reset_prepare` list or `null` as specified above.
- Every training probe additionally has `observed_features`, with length
  `len(readout_after) * len(observables)`.  Held-out probes do not expose it.

Infer the shared parameters from all training probes and predict the feature
vectors for every held-out probe in input order.

Return a dictionary with exactly these entries:

```python
{
    "estimated_parameters": np.ndarray,  # shape (6,), parameter_names order
    "training_rmse": float,
    "heldout_features": np.ndarray,      # (n_heldout, feature_dimension)
}
```

`training_rmse` is the root mean square over all scalar differences between
the model-predicted features and `observed_features`, concatenated across all
training probes in input order.

The retained-memory density-matrix evolution, causal breaks, and damping must
use the quantum software framework selected for the run. Framework-specific
constraints are supplied separately. NumPy and SciPy may be used for
deterministic bounded fitting, but not to replace the framework's quantum or
open-system simulation. Results must be deterministic and finish within 300
seconds. The solution must not read evaluator files, hidden seeds, `/tests`,
`/logs`, or any oracle solution.
